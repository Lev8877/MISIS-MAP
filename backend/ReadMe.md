# Карта МИСиС: бэкенд

API для карты корпусов МИСиС: этажи, помещения, поиск аудитории и кратчайший маршрут от одного кабинета до другого.

Сейчас это каркас с заглушками. Данные лежат в fake_data.py, базы данных пока нет. Когда будет готова БД, нужно будет переписать только services/: роутеры и схемы останутся такими же, и фронтенду ничего менять не придётся.

## Стек

Python 3.13  
FastAPI, Pydantic  
Pytest, TestClient

## Возможности

Список этажей и данные этажа  
Список помещений, фильтр по этажу  
Карточка помещения  
Поиск по номеру и названию без учёта регистра  
Кратчайший маршрут между помещениями, в том числе с переходом между этажами (алгоритм Дейкстры)

## Как устроен граф

Узел графа — это точка на плане этажа: дверь аудитории, точка коридора или лестница. У узла есть этаж и координаты x, y в системе координат SVG-плана.  
Ребро соединяет два узла, его длина задаётся в метрах. Лестница — это ребро между узлами двух этажей.  
Каждое помещение привязано к своему узлу через node_id.

Маршрут возвращается как список узлов по порядку. Фронтенд рисует линию по точкам каждого этажа.

## Локальный запуск

Создать виртуальное окружение и установить зависимости:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Запустить приложение:

```powershell
uvicorn main:app --reload
```

Swagger: [http://localhost:8000/docs](http://localhost:8000/docs)

## Тесты

```powershell
py -m pytest -v
```

## Основные маршруты

GET /floors: Список этажей  
GET /floors/{floor_id}: Получение этажа  
GET /rooms: Список помещений, параметр floor_id необязательный  
GET /rooms/{room_id}: Карточка помещения  
GET /search?query=: Поиск помещений  
GET /route?from_room_id=&to_room_id=: Кратчайший маршрут

## Коды ответов

200: успешный запрос  
404: этаж, помещение или маршрут не найдены  
422: некорректные параметры запроса
